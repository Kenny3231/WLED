# Photos des panneaux

Déposez ici vos photos avec exactement ces noms (en minuscules) :

| Fichier | Photo |
|---|---|
| `panneau-1.jpg` | vue d'ensemble des deux panneaux |
| `panneau-2.jpg` | gros plan sur un affichage |
| `panneau-3.jpg` | câblage et carte, à l'arrière |

La page les affiche dès qu'elles sont poussées sur la branche `gh-pages`. Largeur conseillée : environ 1600 pixels.

**Avant de les publier :** supprimez les données de localisation (GPS) de vos photos. Sous Windows : clic droit sur le fichier, Propriétés, Détails, « Supprimer les propriétés et les informations personnelles ». Vérifiez aussi qu'aucune adresse, étiquette ou écran personnel n'apparaît dans le cadre.
